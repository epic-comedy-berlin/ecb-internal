Keep connectors off unless you're using them

Connectors are the integrations that let Claude reach other tools — pulling a transcript, posting to Slack, updating a task. The simple rule, whatever's in the list: leave them all off by default, turn one on only for the message that actually needs it, then turn it off again. It keeps each chat lean and avoids leaving access switched on when it isn't doing anything.

Blue = on. Grey = off. Changes take effect from your next message.

Turn it off again after

If you turn a connector on for a specific message — say, toggling Fireflies on to pull a transcript — turn it off again once you've got what you needed. It stays on for the rest of the chat until you switch it off, and there's no reason to leave access open when only one message needed it.

Switch on "Load tools when needed"

At the bottom of the connector panel there's a Tool access — Load tools when needed setting. Turn it on. It tells Claude to only pull in a connector's tools when it actually needs them for what you've asked, rather than loading everything up front. Leave it on as the default — it's the main lever for keeping connectors from adding overhead, and it works no matter how many connectors are in the list.

Which connectors to turn on

Default for every connector: off. Turn one on only for the specific task that needs it, then turn it off again. The connectors below are the ones currently in the panel — examples of the rule, not a fixed list.

Connector Turn on when... Leave off for...
Fireflies Pulling meeting transcripts — MIRs, task scans, log updates Briefings, writing, research, everything else
Zapier Building or debugging automations, or posting to Slack Briefings, copy tasks, newsletter, strategy
ClickUp Explicitly pushing task updates or marking completions (e.g. a Mode 4 handoff) Briefings, copy, research — everything else
Google Drive A task genuinely needs a file from Drive Everything else — off by default
When you see a connector that isn't listed here

New connectors get added over time, so the panel may show ones this guide doesn't name. The rule is always the same: off unless the task in front of you needs it, on for that task, off again after. You don't need this guide to list a connector to know how to treat it — every connector follows the same rule.

Check the 5-hour window first

The account budget resets every five hours from your first message — not at midnight or any fixed time of day. If you start at 2pm, the reset might not come until 7pm. Check before starting anything long or Opus-heavy.

How to find the usage screen

Click your account name in the bottom-left corner of Claude, then go to Settings.

Inside Settings, click Usage in the left sidebar.

2

Settings → Usage — current session bar shows how much of the 5-hour window is used and when it resets

Account name (bottom-left) → Settings → Usage

The Current session bar shows how much of the 5-hour budget is used and how long until it resets. If the bar is nearly full, wait for the reset or post in #p1-important so the rest of the team knows.

Standing rule — Aaron, 4 May

Nobody uses Claude in the three hours before a scheduled team meeting. Meetings are when we most need the account unblocked. Finish heavy work before the window starts.

Flag heavy work before you start

If your task is time-sensitive and will use a lot of Opus, post in #p1-important first. Not asking permission — just making sure nobody else fires a big session at the same time and tips the account over the limit mid-task.
